# Changelog

## v6.2.0 (2026-11-16)

- First release of the template: listmonk v6.2.0 (`listmonk/listmonk:v6.2.0@sha256:f535d59e14991337a9f2d570273685378ae86b0d7698c3e00da444e3bc205286`) with Railway Postgres.
- Super admin created on first boot from `LISTMONK_ADMIN_USER` and a generated `LISTMONK_ADMIN_PASSWORD`.
- Root URL set to the Railway public domain on first boot; media uploads on a volume at `/listmonk/uploads`.
